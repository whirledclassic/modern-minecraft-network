## Server icon in Minecraft

Save the square emblem as `server-icon.png` (64×64) and drop it in the Velocity or lobby data folder if you want it in the multiplayer list. The SVG is the source.

Do not add a cape-like logo. Mojang treats fake capes as off-limits.
